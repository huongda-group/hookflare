## [1.0.0] - 2026-11-23

First release: inbound webhook gateway on Cloudflare Workers with source
authentication, at-least-once signed delivery with retries and replay, the
operator dashboard, built-in login with API tokens and RBAC, alerts, archival,
and D1 backups. See the [feature documentation](https://github.com/huongda-group/hookflare/tree/1.0.0/docs)
at this tag and the [installation guide](https://github.com/huongda-group/hookflare/tree/1.0.0#installation).
